# apps-script/ — โค้ด Google Apps Script ตัวที่ deploy อยู่จริง

## วางไฟล์ที่นี่

| ไฟล์ในโปรเจกต์ Apps Script | วางเป็นชื่อนี้ |
|---|---|
| `Code.gs` (หรือชื่ออื่นที่มี `doPost`) | `apps-script/Code.gs` |
| ถ้ามีไฟล์ `.gs` อื่น ๆ | ชื่อเดิม เช่น `apps-script/Utils.gs` |
| ถ้ามีไฟล์ `.html` | ชื่อเดิม เช่น `apps-script/Index.html` |
| `appsscript.json` (ถ้าเปิดให้เห็น) | `apps-script/appsscript.json` |

สร้างไฟล์เปล่าแล้ววางทับได้เลย ไม่ต้องแก้อะไร

## ทำไมต้องเอามาเก็บ

โค้ดที่ commit ไว้เดิม (`AppsScript-โค้ด.gs` ที่ root) เป็น **VERSION 9** แต่
`โมเดลเดินรถ-gsheet-v5.html:1686` บังคับ `GS_VERSION = 10` และเรียก action
`{loadTrips:true}` ซึ่ง v9 ไม่มี — แปลว่าโค้ดใน repo ใช้กับแอปปัจจุบันไม่ได้จริง
ตัวจริงมีอยู่แค่บน Google เท่านั้น ถ้าโปรเจกต์นั้นหายหรือถูกแก้ทับ = กู้ไม่ได้

สิ่งที่มีเฉพาะในตัว v10 และหายไปจาก git:
- action `loadTrips`
- คอลัมน์ 53-60: `วันที่ปล่อยรถ` + workflow 3 ฝ่าย
  (`สถานะฝ่ายบริการลูกค้า`, `เวลาบริการลูกค้ากรอก`, `สถานะฝ่ายจัดรถ`,
  `เวลาจัดรถกรอก`, `สถานะฝ่ายบัญชี`, `เวลาบัญชีกรอก`, `ความครบถ้วน`)
- คอลัมน์ 61 `_DATA` — JSON เต็มของ record เป็นที่เดียวที่ round-trip ได้ครบ

### เช็คก่อนว่าใช่ตัวถูก
ในโค้ดต้องเจอทั้งสองอย่างนี้:
- `function doPost(e)`
- `var VERSION = 10`

ถ้าเจอ `google.script.run` แต่ไม่มี `doPost` แสดงว่าเป็นคนละโปรเจกต์
(ตัวนั้นคือ `AppsScript-โมเดลเดินรถ/` ที่ root ซึ่ง React เรียกไม่ได้)

### ถ้า deploy ค้างเวอร์ชันเก่า
เอา URL `/exec` ที่บันทึกไว้ในแอป v5 (หน้า "รายการทั้งหมด" → ตั้งค่า Google Sheet)
ไปเปิดในเบราว์เซอร์ จะได้ JSON กลับมาเช่น `{"ok":true,"version":10,...}`
- ขึ้น `10` = ตรงกับที่แอปต้องการ
- ขึ้น `9` = deploy ค้างเวอร์ชันเก่า ต้อง Deploy ใหม่เป็น New version
