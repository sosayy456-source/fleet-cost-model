## 0. นิยาม "เที่ยววิ่งเปล่า" — เปลี่ยนทั้งระบบ

**เดิม** `empty = ประเภทใบรายการ ∈ {ของเหมาตีเปล่า, รถว่างไปสาขา}`

**ใหม่** เที่ยววิ่งเปล่า = แถวที่ **`ราคารวมจากรายได้` = 0 และ `ค่าบรรทุกทั้งใบรายการ` = 0** พร้อมกัน
(= เที่ยวที่ไม่มีรายได้เลย) **ไม่จำกัดประเภทใบรายการ** — ส่วนใหญ่เป็น `รถว่างไปสาขา` แต่ประเภทอื่นก็เข้าข่ายได้

เจ้าของยืนยันให้ **เปลี่ยนทั้งระบบ** ไม่ใช่เฉพาะแท็บใหม่

### ที่ต้องแก้

| ไฟล์ | จุด |
|---|---|
| `etl/build_costrev.py` | `"empty": ttype in EMPTY_TYPES` → เช็คสองคอลัมน์เป็นศูนย์ · ลบ/เลิกใช้ `EMPTY_TYPES` · `manifest.emptyTypes` แทนด้วยคำอธิบายนิยามใหม่ · แก้ docstring บรรทัด "เที่ยวตีเปล่า" |
| `app/src/features/dash-costrev/FleetTab.tsx` | ใช้ `t.empty` อยู่ 3 ที่ (การ์ดเที่ยวตีเปล่า · ต้นทุนเที่ยวตีเปล่า · แถบสุขภาพกองรถ) — ตัวเลขจะเปลี่ยน **ถูกต้องแล้ว** เปลี่ยนคำว่า "ตีเปล่า" เป็น "วิ่งเปล่า" ให้ตรงนิยามใหม่ |
| `app/src/lib/data/useCostRev.ts` | คอมเมนต์ของ `empty` |
| `CLAUDE.md` | บรรทัดนิยาม `เที่ยวตีเปล่าดูจาก ประเภทใบรายการ` |

### ★ กับดักที่ต้องระวัง

`rev` ใน `trips.json` **ใช้แทนเงื่อนไขใหม่ตรง ๆ ไม่ได้** เพราะ ETL คำนวณ

```python
rev1 = num_or_none(g(r, COL_REV1))            # ราคารวมจากรายได้
revenue = rev1 if rev1 is not None else num(g(r, COL_REV2))   # ว่างค่อยใช้ ค่าบรรทุกทั้งใบรายการ
```

ถ้า `ราคารวมจากรายได้` มีค่าเป็น 0 จริง ๆ (ไม่ใช่ช่องว่าง) `revenue` จะเป็น 0 ทันทีโดยไม่ดู `ค่าบรรทุก`
→ **ต้องอ่านสองคอลัมน์แยกกันตอนสร้าง `empty` ใน ETL** อย่าใช้ `t.rev === 0` ในฝั่งแอป

วัดกับ `etl/sample_data/ExampleCost.xlsx` แล้ว ชุดตัวอย่างสองทางให้ผลเท่ากันพอดี (287 แถว)
แต่นั่นเป็นเรื่องบังเอิญของชุดตัวอย่าง **ข้อมูลจริงไม่รับประกัน** — เขียนให้ถูกตามนิยาม

### ผลกับชุดตัวอย่าง (ไว้เทียบว่าทำถูก)

```
นิยามใหม่ 287 แถว จาก 4,402  = ของเหมาตีเปล่า 141 · รถว่างไปสาขา 140 · ของเหมา 5 · ของสด 1
นิยามเดิม 281 แถว            = ของเหมาตีเปล่า 141 · รถว่างไปสาขา 140
```

## 1. หลักการคำนวณหลัก (เจ้าของเขียนเอง)

1. ดึงข้อมูลเส้นทางทั้งหมดของเที่ยววิ่งเปล่า
2. ดึงต้นทุนเที่ยววิ่งเปล่าของแต่ละเส้นทาง
3. ดึงต้นทุนรวมของแต่ละเส้นทาง
4. **ข้อ 2 ÷ ข้อ 3**

**ตัวหาร "ต้นทุนวิ่งรถทั้งหมด" = ต้นทุนของทุกเที่ยว รวมเที่ยวเปล่าด้วย** (ยืนยันแล้ว ข้อ 3 ของคำถาม)
ใช้กติกาเดียวกันทุกที่ที่มีเครื่องหมาย % ในเอกสารนี้

เส้นทาง = ฟิลด์ `rt` (จุดขึ้น-จุดลง) เหมือนแท็บอื่น · ต้นทุน = `cost` · ปี = `y` · เดือน = `mo`

## 3. ลำดับการเล่าเรื่อง (ภาพใหญ่ → รายละเอียด)

### [KPI Card] บนสุด — ตัวเลขใหญ่ 3 ตัว

1. มูลค่าต้นทุนเที่ยวเปล่ารวม 3 ปี (บาท)
2. จำนวนเที่ยวเปล่ารวม 3 ปี (เที่ยว)
3. % เที่ยวเปล่าต่อต้นทุนทั้งหมด **ปีล่าสุด**

> ปีล่าสุด = ปีล่าสุดที่มีข้อมูลจริง (ชุดตัวอย่างคือ 2569 ซึ่งมีถึง พ.ค. เท่านั้น)
> **ต้องเขียนกำกับใต้การ์ดว่าปีนั้นยังไม่เต็มปี** (ยืนยันแล้ว ข้อ 4)

### [1] % ต้นทุนเที่ยวเปล่า ÷ ต้นทุนวิ่งรถทั้งหมด (รายปี 3 ปี) — ภาพรวมทั้งบริษัท

- **Line Chart 3 จุด** (ปี 1-2-3) ดูแนวโน้ม
- **เอากราฟเสริมด้วย** (ยืนยันแล้ว ข้อ 5): **100% Stacked Bar ต่อปี** — เที่ยวเปล่า vs เที่ยวมีรายได้ (มูลค่าบาท)

### [2] Top 10 เส้นทางที่วิ่งเที่ยวเปล่าบ่อยสุด (รวม 3 ปี)

- Horizontal Bar Chart เรียงมาก → น้อย
- แกน Y = ชื่อเส้นทาง · แกน X = **จำนวนเที่ยว** (นับจำนวนแถว)

### [3] Top 10 เส้นทางที่ต้นทุนเที่ยวเปล่าสูงสุด (รวม 3 ปี)

- Horizontal Bar Chart เรียงมาก → น้อย
- แกน Y = ชื่อเส้นทาง · แกน X = **มูลค่าต้นทุนรวม (บาท)**
- **วางคู่กับข้อ [2] แบบ side-by-side** (ต้นฉบับพิมพ์ "[1]" เจ้าของยืนยันว่าหมายถึง [2] — ข้อ 6)

### [4] % ต้นทุนเที่ยวเปล่าของเส้นทางนั้น ÷ ต้นทุนวิ่งรถทั้งหมดของเส้นทางนั้น (รายเส้นทาง รวม 3 ปี)

ตารางตั้งต้น 3 คอลัมน์ → เส้นทางทั้งหมดของเที่ยวเปล่า · ต้นทุนเที่ยวเปล่าของเส้นทางนั้น · ต้นทุนรวมของเส้นทางนั้น
แล้วหารกัน

- **วัตถุประสงค์:** ชี้เส้นทางที่มีสัดส่วนเที่ยวเปล่าสูงสุดเทียบกับเที่ยวทั้งหมดของเส้นทางนั้น
  (ไม่ใช่แค่เส้นทางที่วิ่งบ่อยหรือแพงสุด)
- **เกณฑ์กรองสำคัญ:** นับเฉพาะเส้นทางที่มีจำนวนเที่ยวรวม (เปล่า + มีรายได้) **≥ 20 เที่ยว** ใน 3 ปี
  (ยืนยันแล้ว ข้อ 7 — เอา 20 ก่อน) ไม่งั้นเส้นทางที่วิ่งน้อยมากจะขึ้น % สูงผิดปกติแล้วติด Top
  ทั้งที่มูลค่าจริงไม่มีนัย · **ต้องกรองก่อนแสดงทุกครั้ง**
- **รูปแบบ: Scatter Plot** (ยืนยันแล้ว ข้อ 7)
  - แกน X = มูลค่าต้นทุนเที่ยวเปล่า (บาท)
  - แกน Y = % ต่อเส้นทาง
  - ขนาดจุด = จำนวนเที่ยว
  - เส้นทางมุมขวาบน = เป้าหมายที่ต้องแก้ก่อน
- ชุดตัวอย่าง: เส้นทางที่เที่ยวรวม ≥ 20 มี 59 เส้นทาง (≥ 30 มี 45) จากทั้งหมด 178

### [5] % ต้นทุนเที่ยวเปล่า ÷ ต้นทุนวิ่งรถทั้งหมด (รายเดือน) — เส้นทาง peak

- **Bar Chart รายเดือน แบบไล่ตามเวลาจริง** (ยืนยันแล้ว ข้อ 8 = ข้อ ข.)
  ชุดตัวอย่างคือ 25 เดือน ม.ค. 2567 → พ.ค. 2569 **ไม่ใช่** ยุบรวมเป็น 12 เดือนแบบดูฤดูกาล
- **Dropdown เลือกเส้นทาง**
  - ค่าเริ่มต้นอัตโนมัติ = **เส้นทางที่มีต้นทุนเที่ยวเปล่ารวมสูงสุด**
  - ผู้ใช้เปลี่ยนได้ เลือกได้ทั้ง **1 เส้นทาง หรือหลายเส้นทาง**
  - เลือกหลายเส้นทาง → **Grouped Bar Chart** แยกสีตามเส้นทาง
