# travel/ — ค่าเดินทาง (ยังไม่มีข้อมูล)

โฟลเดอร์นี้เตรียมไว้รอ ยังไม่มี loader เพราะยังไม่เห็นไฟล์จริง

ขั้นตอนเหมือน `repair/` — วางไฟล์ แล้วรัน
`python build_json.py --dataset real --inspect travel` เพื่อดูชื่อคอลัมน์จริง
จากนั้นเติมลงใน `etl/src/loaders/travel.py`

หมายเหตุ: ชื่อ "ค่าเดินทาง" ซ้ำกับชื่อแท็บใน Google Sheet ที่เก็บใบรายการเดินรถ
ถ้าไฟล์ที่ได้มาเป็นข้อมูลชุดเดียวกับแท็บนั้น อาจไม่ต้องมี loader แยก
ให้ดึงผ่าน action `loadOld` ของ Apps Script แทน
