# etl/data/debtors/

วางไฟล์ **ใบวางบิลลูกหนี้** (`.xlsx`) ไว้ที่นี่ แล้ว dev server จะแปลงให้เองภายใน 2-3 วินาที
(plugin `autoEtl` ใน `app/vite.config.ts` → `python etl/build_debtors.py --dataset real`)
ผลลัพธ์ไปที่ `app/public/data/real/debtors/` ซึ่งแท็บ "Dashboard ลูกหนี้" อ่านอยู่

คอลัมน์ที่ต้องมี (ชื่อต้องตรงเป๊ะ):

| คอลัมน์ | ความหมาย |
|---|---|
| `ชื่อลูกหนี้` | รหัสลูกหนี้ที่ hash มาแล้วจากต้นทาง |
| `สาขา` | ชื่อสาขา |
| `ระยะเวลาเครดิต` | จำนวนวันเครดิต **ของใบนั้น** (ตัวอย่างมี 7 / 15 / 30) |
| `เลขที่ใบวางบิล` | 13 หลัก |
| `วันที่วางบิลได้` | วันที่เริ่มนับเครดิต (รับ `วันที่วางบิล` ด้วย) |
| `วันที่จบ` | วันที่ปิดบัญชี — **เว้นว่าง = ยังค้างชำระ** |
| `จำนวนเงิน` | ยอดของใบวางบิล |

ไฟล์รุ่นใหม่ `ข้อมูลการรับชำระ_วิเคราะห์ 99.xlsx` (22 ก.ย. 2569) มีสองชีต — ETL อ่านข้อมูลรายใบจากชีต
`Sheet1` (ถ้าไม่มีชีตชื่อนี้ค่อยใช้ชีตแรก) และอ่าน "วันที่อ้างอิง" จากชีต `สรุปวิเคราะห์` ไปเป็นค่าเริ่มต้นของ
ช่อง "ข้อมูล ณ วันที่" ในแท็บกำไรลูกค้าของเมนู Demo · คอลัมน์วิเคราะห์ที่เพิ่มมาในไฟล์ไม่ถูกอ่าน
(แอปคำนวณสถานะเองจากวันที่ที่เลือก) · `วันที่จบ` ที่เป็นข้อความ "(ว่าง)" = ยังค้างชำระ

ช่องวันที่รับได้ทั้งเซลล์วันที่ ข้อความ `dd/mm/yy` และ**เลขลำดับวันของ Excel** (เช่น `46030` = 8 ม.ค. 2026 —
ไฟล์ "สุ่ม 1200 บิล.xlsx" เป็นแบบนี้ ETL รุ่นก่อน 23 ก.ย. 2569 ข้ามทิ้งทุกแถว) · ยอดเงินที่เป็นข้อความมีคอมมาก็อ่านได้

ชื่อหัวคอลัมน์รับได้หลายแบบต่อช่อง (ดู `ALIASES` ใน `etl/build_debtors.py`) และตัดช่องว่างซ้ำ
ทิ้งก่อนเทียบ — ถ้าไฟล์ใหม่ใช้ชื่ออื่น ETL จะฟ้องพร้อมบอกหัวตารางที่อ่านได้จริง เติมชื่อลง
`ALIASES` ได้เลย ไม่ต้องแก้ไฟล์ Excel

ไฟล์ในโฟลเดอร์นี้ไม่ขึ้น repo (`.gitignore` กัน `etl/data/*` ไว้แล้ว ยกเว้น README)

**ชุดตัวอย่างก็ไม่ขึ้น repo เหมือนกัน** — `etl/sample_data/ExampleDebtors.xlsx` กับ
`app/public/data/sample/debtors/` ติด `.gitignore` เพราะถอดมาจากรายงานจริง
มียอดเงิน วันที่ และชื่อสาขาของจริง (ต่างจากไฟล์บิลตัวอย่างที่ anonymize มาแล้ว)
คนที่ clone ไปจึงต้องมีไฟล์ของตัวเอง แล้วรัน `python etl/build_debtors.py --dataset real`
— ถ้ายังไม่มี แท็บ "Dashboard ลูกหนี้" จะขึ้นข้อความบอกวิธีสร้างไฟล์ให้เอง
