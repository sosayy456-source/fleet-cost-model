# โฟลเดอร์ข้อมูลจริง

**ทุกอย่างใต้ `etl/data/` ติด .gitignore แล้ว** ไฟล์ในนี้จะไม่ขึ้น GitHub
ตรวจด้วย `git status` ก่อน push ทุกครั้งเพื่อความมั่นใจ

## ใส่ไฟล์ไหนที่ไหน

หนึ่งเอกสาร = หนึ่งโฟลเดอร์ **ไม่ต้องวางไฟล์เดียวกันซ้ำหลายที่** ระบบอ่านร่วมกันเอง

| โฟลเดอร์ | เอกสาร | สคริปต์ที่อ่าน |
|---|---|---|
| `revenue/` | **ไฟล์บิล (รายได้)** รายเดือน | `build_json.py` · `build_costrev.py` · `build_alloc.py` |
| `Dashboard real data/` | ไฟล์**ต้นทุนรายเที่ยว** `RealCostandRevenue.xlsx` | `build_costrev.py` |
| `travel/` | รายงาน**ค่าเดินทาง** | `build_alloc.py` |
| `debtors/` | **ใบวางบิลลูกหนี้** | `build_debtors.py` |
| `Loadfactor/` | **Load Factor รายเที่ยว** (คอลัมน์ชุดเดียวกับ `ExampleLoadfactor.xlsx`) | `build_loadfactor.py` → แท็บ "ต้นทุนที่จมกับที่ว่าง" |
| `repair/` | รายงาน**ค่าซ่อม** | ยังไม่มีสคริปต์ — นำเข้าผ่านหน้า "การตั้งค่า" ในแอปแทน |

## ไฟล์รายได้ป้อนสามแดชบอร์ดพร้อมกัน

วาง `.xlsx` ลง `revenue/` ที่เดียว แล้วทั้งสามงานนี้ได้ข้อมูลชุดเดียวกันหมด:

```
etl/data/revenue/*.xlsx
   ├→ build_json.py     → data/real/*.json       → Dashboard รายได้ (แนวโน้ม/ชำระเงิน/เส้นทาง/ลูกค้า)
   ├→ build_costrev.py  → data/real/costrev/     → กองรถ · กำไรรายเที่ยว · ต้นทุน
   │     (จับคู่เลขที่ใบรายการกับไฟล์ต้นทุน และสร้าง old_debtors ให้แท็บ "จากข้อมูลบิล (เดิม)")
   └→ build_alloc.py    → data/real/alloc/       → กำไรลูกค้า (ปันส่วนต้นทุน)
         (คู่กับรายงานค่าเดินทางใน travel/)
```

plugin `autoEtl` ใน `app/vite.config.ts` สั่งทั้งสามงานให้เองเมื่อไฟล์ใน `revenue/` เปลี่ยน
และ **รันทีละงาน ไม่รันซ้อน** เพราะแต่ละงานกินหน่วยความจำหลาย GB

## วิธีใช้

1. วางไฟล์ `.xlsx` ลงในโฟลเดอร์ที่ตรงประเภท ไม่ต้องเปลี่ยนชื่อไฟล์
   ระบบอ่านทุกไฟล์ในโฟลเดอร์เองโดยดูจากคอลัมน์ ไม่ได้ดูจากชื่อไฟล์
2. ถ้า `npm run dev` รันอยู่ ระบบจะแปลงให้เองภายในไม่กี่วินาที (ดู `[etl]` ใน terminal)
   ถ้าไม่ได้รันอยู่ ให้รันสคริปต์ที่ตรงกับโฟลเดอร์เองด้วย `--dataset real`
3. แดชบอร์ดขึ้น "⏳ กำลังแปลง…" แล้ว**รีเฟรชเองเมื่อเสร็จ** — ถ้ารัน ETL เองตามข้อ 2
   ให้กดปุ่ม **↻ รีเฟรชข้อมูล** แทน · ไม่ต้องรีสตาร์ท server ทั้งสองกรณี
4. ลบไฟล์ออกจนโฟลเดอร์ว่าง = ระบบล้าง JSON ของงานนั้นทิ้งแล้วกลับไปใช้ชุดตัวอย่าง

ไฟล์ที่ระบบข้ามให้อัตโนมัติ: `~$*` (ไฟล์ล็อกของ Excel) และ `*.backup.*`

## ที่เคยมีแล้วเลิกใช้

`allocated/` — เคยรับไฟล์ที่ปันส่วนเสร็จแล้วจากเครื่องปันส่วนต้นทุน V2
เจ้าของข้อมูลสั่งตัดทิ้ง **17 ก.ย. 2569** เพราะเป็นข้อมูลชุดเดียวกับที่ `revenue/` กับ `travel/`
มีอยู่แล้ว แค่ผ่านการคำนวณมาก่อน — เก็บไว้สองที่คือข้อมูลซ้ำซ้อน
ตอนนี้ `build_alloc.py` คำนวณเองจากไฟล์ดิบเสมอ ตรวจแล้วผลลัพธ์เท่าเดิมทุกไบต์
