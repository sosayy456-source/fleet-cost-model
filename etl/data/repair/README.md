# repair/ — ค่าซ่อมแซม (ยังไม่มีข้อมูล)

โฟลเดอร์นี้เตรียมไว้รอ ยังไม่มี loader เพราะยังไม่เห็นไฟล์จริง

เมื่อได้ไฟล์มาแล้ว:
1. วางไฟล์ `.xlsx` ที่นี่
2. เปิด `etl/src/loaders/repair.py` แล้วเติมชื่อคอลัมน์จริงลงใน `EXPECTED_COLUMNS`
3. รัน `python build_json.py --dataset real --inspect repair`
   จะพิมพ์ชื่อคอลัมน์ที่เจอจริงในไฟล์ออกมาให้ก็อปไปใส่ได้เลย

ข้อมูลที่โมเดลต้นทุนน่าจะใช้ได้: ทะเบียนรถ, วันที่ซ่อม, ประเภทการซ่อม, ค่าใช้จ่าย
ถ้ามีสามอย่างแรกครบจะแทนที่ตารางค่าซ่อมแบบถัวเฉลี่ย 3 ปีที่ใช้อยู่ตอนนี้ได้
(ดู `app/src/lib/refdata/repair.json` — ตอนนี้ 9 จาก 12 ชนิดรถยังมีข้อมูลไม่ครบ)
