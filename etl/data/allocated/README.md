# allocated/ — ไฟล์ที่ปันส่วนต้นทุนเสร็จแล้ว (จากเครื่องปันส่วนต้นทุน V2)

วางไฟล์ `.xlsx` ที่เครื่องปันส่วนต้นทุนส่งออกมาที่นี่ กี่ไฟล์กี่เดือนก็ได้
ระบบอ่านทุกไฟล์ในโฟลเดอร์เอง ไม่ได้ดูจากชื่อไฟล์ · อ่านชีตแรกของไฟล์

**มีไฟล์ในโฟลเดอร์นี้ = ระบบใช้ตัวเลขจากไฟล์นี้** ไม่คิดสูตรปันส่วนใหม่
(ถ้าโฟลเดอร์ว่าง ระบบจะถอยไปคำนวณเองจาก `travel/` + `revenue/` ด้วย `src/alloc.py`)

## คอลัมน์ที่ต้องมี

จากไฟล์บิลเดิม (เครื่อง V2 คงคอลัมน์เหล่านี้ไว้ให้อยู่แล้ว):

    เลขที่บิล · เลขที่ใบรายการ · วันที่ · ประเภทการชำระเงิน
    ผู้ส่ง_encoded · ผู้รับ_encoded · ราคารวม · ประเภทสินค้า

จากผลการจัดสรร:

    ต้นทุนจัดสรร (บาท)        ← ยอดที่ระบบอ่านไปใช้ตรง ๆ  (ชื่อ "ต้นทุนจัดสรร" เฉย ๆ ก็ได้)

ไม่บังคับแต่ใส่มาได้ ระบบจะเอาไปแสดงเพิ่ม:

    ต้นทุนเที่ยวรถ (บาท) · ระยะทาง (กม.) · เงื่อนไขที่ใช้
    ต้นทาง · ปลายทาง

คอลัมน์อื่นที่เครื่องส่งมาด้วย (ปริมาตร CBM, เกณฑ์ภาระงาน, สัดส่วนการจัดสรร,
กำไร/ขาดทุนจัดสรร, สถานะผลประกอบการ ฯลฯ) ระบบไม่ใช้ แต่มีมาก็ไม่เสียหาย

## สองข้อที่ขอไว้ในไฟล์ด้วย

1. **แถวที่ปันไม่ได้ให้คงไว้** โดยเขียนคำว่า `ข้อมูลไม่เชื่อมกัน` ในช่องต้นทุนจัดสรร
   ตามที่เครื่อง V2 ทำอยู่แล้ว — ระบบถือว่าแถวนั้น "ไม่มีต้นทุน" ไม่ใช่ต้นทุน 0
   และเอาไปแสดงในบล็อกล่างสุดของหน้า ถ้าตัดแถวทิ้ง ยอดรายได้จะหายไปเงียบ ๆ
2. **อย่าตัดแถวบิลเคลียร์ / ของเหมาตีเปล่า / รถว่างไปสาขาออก** ให้ติดมาด้วย
   ระบบกันออกจากกำไรลูกค้าเอง แล้วแสดงยอดเป็น "ต้นทุนที่ไม่ปันเข้าลูกค้า"

## เที่ยวตีเปล่าต้องมีรายงานค่าเดินทางคู่กัน

ไฟล์จากเครื่อง V2 ไม่มีคอลัมน์ `ประเภทใบรายการ` (อยู่ในรายงานค่าเดินทาง)
ระบบจึงอ่านคอลัมน์นั้นจากไฟล์ใน `etl/data/travel/` ถ้ามี — **ถ้าโฟลเดอร์นั้นว่าง
จะกันออกได้แค่บิลเคลียร์** เที่ยวของเหมาตีเปล่า/รถว่างไปสาขาจะถูกนับเป็นลูกค้าด้วย
(ระบบเตือนใน terminal ตอนรัน)

## วิธีใช้

1. วางไฟล์ที่นี่ (ตอน `npm run dev` รันอยู่ก็ได้)
2. dev server รัน `build_alloc.py --dataset real` ให้เอง (ดู `[etl]` ใน terminal)
3. หน้า **กำไรลูกค้า (ปันส่วนต้นทุน)** ขึ้น "กำลังแปลง…" แล้วรีเฟรชเองเมื่อเสร็จ

รันเองได้ด้วย `python etl/build_alloc.py --dataset real` → `app/public/data/real/alloc/`
เทียบกับที่ระบบคำนวณเองได้ด้วย `--source compute`
