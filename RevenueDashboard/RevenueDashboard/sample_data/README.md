# 📁 ไฟล์ตัวอย่าง (Sample / Randomed Data)

ไฟล์ .xlsx ทั้ง 6 ไฟล์ในโฟลเดอร์นี้เป็น **ข้อมูลตัวอย่างที่สุ่มมาแล้ว** (Randomed sample) จากข้อมูลบิลขนส่งจริง
ใช้สำหรับ **ทดสอบโครงสร้างแดชบอร์ดเท่านั้น** ไม่ใช่ยอดรายได้จริงของบริษัท

## วิธีทดสอบแดชบอร์ดด้วยข้อมูลตัวอย่าง

```bash
# คัดลอกไฟล์ตัวอย่างไปไว้ในโฟลเดอร์ data/ (ที่แอปอ่านข้อมูลจริง)
cp sample_data/*.xlsx data/

# รันแอป
streamlit run app.py
```

จากนั้นเมื่อได้ไฟล์จริงครบทั้ง 29 ไฟล์ ให้:
1. ลบไฟล์ตัวอย่างออกจาก `data/` (`rm data/*Randomed*.xlsx`)
2. นำไฟล์จริงมาวางแทนใน `data/`
3. กด "รีเฟรชข้อมูล" ในแอป — ไม่ต้องแก้โค้ดใดๆ ทั้งสิ้น

## หมายเหตุ

- ไฟล์ในโฟลเดอร์นี้ปลอดภัยที่จะ commit ขึ้น GitHub ได้ (ถูกยกเว้นจาก `.gitignore` โดยเฉพาะ) เพราะเป็นข้อมูลตัวอย่างที่ไม่ใช่ข้อมูลลูกค้าจริง
- โครงสร้างคอลัมน์ของไฟล์ตัวอย่างเหมือนไฟล์จริงทุกประการ ต่างกันแค่จำนวนแถว (ไฟล์จริงจะมีแถวมากกว่านี้มาก)
