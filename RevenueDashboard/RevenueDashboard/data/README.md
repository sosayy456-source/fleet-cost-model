# 📁 โฟลเดอร์ข้อมูลจริง (data/)

**โฟลเดอร์นี้สำหรับวางไฟล์ข้อมูลบิลขนส่ง (.xlsx) จริงของบริษัทเท่านั้น**

## วิธีใช้งาน

1. นำไฟล์ .xlsx รายเดือนทั้ง 29 ไฟล์ (ม.ค. 2567 – พ.ค. 2569) มาวางไว้ในโฟลเดอร์นี้
2. ไม่ต้องเปลี่ยนชื่อไฟล์ หรือเรียงลำดับใดๆ — ระบบจะอ่านทุกไฟล์ `.xlsx` ในโฟลเดอร์นี้โดยอัตโนมัติ
3. ไฟล์ต้องมีคอลัมน์ตรงตามพจนานุกรมข้อมูลเดิม (เลขที่บิล, วันที่, ราคารวม, ประเภทการชำระเงิน ฯลฯ)
4. เปิดแอป (`streamlit run app.py`) แล้วกด **🔄 รีเฟรชข้อมูล** ที่แถบด้านซ้าย
5. เมื่อมีไฟล์เดือนใหม่ในอนาคต ก็แค่นำมาวางเพิ่มในนี้แล้วรีเฟรช **ไม่ต้องแก้โค้ดใดๆ**

## ⚠️ ข้อควรระวังด้านความลับของข้อมูล (สำคัญมาก)

- **ห้าม commit ไฟล์ในโฟลเดอร์นี้ขึ้น GitHub** — มีการตั้งค่า `.gitignore` ป้องกันไว้แล้ว (`data/*.xlsx` ถูกยกเว้นอัตโนมัติ) แต่ควรตรวจสอบด้วยตนเองก่อน push ทุกครั้ง
- **ห้ามอัปโหลดไฟล์ในโฟลเดอร์นี้ขึ้นบริการคลาวด์ใดๆ** (Streamlit Cloud, Google Drive แชร์สาธารณะ ฯลฯ)
- แดชบอร์ดนี้ถูกออกแบบให้ทำงาน **บนเครื่อง Local เท่านั้น** (`localhost:8501`) ข้อมูลจะไม่ถูกส่งออกจากเครื่องนี้เลย
- หากต้องการทำ Portfolio/สาธิตให้คนอื่นดู ให้ใช้ไฟล์ตัวอย่างในโฟลเดอร์ `sample_data/` แทน (เป็นข้อมูลที่สุ่ม/anonymize แล้ว)

## โฟลเดอร์นี้ว่างเปล่าโดยตั้งใจ

โฟลเดอร์นี้ไม่มีไฟล์ข้อมูลอยู่ในตอนนี้ (เพื่อไม่ให้ deliverable นี้มีข้อมูลจริงติดไปด้วย) — กรุณานำไฟล์จริงมาวางเองตามขั้นตอนด้านบน
