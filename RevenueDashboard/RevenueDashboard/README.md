# 🚚 Revenue Analysis Dashboard

แดชบอร์ดวิเคราะห์รายได้บิลขนส่งสินค้า (LTL) ทำงาน **บนเครื่อง Local เท่านั้น** ไม่มีการอัปโหลดข้อมูลบริษัทออกสู่อินเทอร์เน็ต

สร้างด้วย Python + pandas + Streamlit + Plotly ตามสถาปัตยกรรมที่ออกแบบไว้ในเอกสารโครงงาน
(อ่าน Excel → ทำความสะอาด → รวมข้อมูล → คำนวณ KPI → สร้าง Insight → แสดงผลบน Streamlit)

---

## 🔒 หลักการด้านความปลอดภัยของข้อมูล

| หลักการ | การดำเนินการในโปรเจกต์นี้ |
|---|---|
| ข้อมูลต้องไม่ออกจากเครื่อง | แอปรันแบบ `localhost` เท่านั้น ไม่มีการเรียก API ภายนอกใดๆ กับข้อมูลบิล |
| ห้ามอัปโหลดขึ้น GitHub | `.gitignore` บล็อก `data/*.xlsx` โดยอัตโนมัติ — commit ได้เฉพาะโค้ดกับไฟล์ตัวอย่างใน `sample_data/` |
| ห้ามใช้ Streamlit Cloud กับข้อมูลจริง | README นี้เตือนไว้ชัดเจน ใช้ Streamlit Cloud ได้เฉพาะกับ `sample_data/` เพื่อทำ portfolio เท่านั้น |
| รองรับไฟล์ใหม่โดยไม่แก้โค้ด | ระบบอ่านทุกไฟล์ `.xlsx` ในโฟลเดอร์ `data/` อัตโนมัติ (ดู `src/data_loader.py`) |

## 📂 โครงสร้างโปรเจกต์

```
RevenueDashboard/
├── data/                  ← วางไฟล์ .xlsx จริงของบริษัทที่นี่ (ว่างเปล่าตอนนี้โดยตั้งใจ)
│   └── README.md
├── sample_data/           ← ไฟล์ตัวอย่างที่สุ่มแล้ว 6 ไฟล์ (ใช้ทดสอบแอปได้ทันที)
│   └── README.md
├── src/
│   ├── data_loader.py     ← ค้นหา + โหลดไฟล์ .xlsx ทั้งหมดใน data/ อัตโนมัติ (มี cache)
│   ├── cleaning.py        ← แปลงวันที่ พ.ศ.→ค.ศ., แปลงตัวเลข, ติดธงข้อมูลผิดปกติ
│   ├── kpi.py              ← คำนวณ KPI และตารางสรุปทั้งหมด
│   └── insights.py         ← สร้างข้อความ insight อัตโนมัติจากตัวเลขจริง (ไม่ใช่ข้อความตายตัว)
├── app.py                  ← แอป Streamlit หลัก (8 หน้า)
├── requirements.txt
├── .streamlit/config.toml  ← ธีมสี
└── .gitignore               ← ป้องกันข้อมูลจริงหลุดขึ้น GitHub
```

## 🚀 วิธีติดตั้งและรัน (ครั้งแรก)

```bash
# 1. เข้าไปในโฟลเดอร์โปรเจกต์
cd RevenueDashboard

# 2. สร้าง virtual environment (แนะนำ)
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # Mac/Linux

# 3. ติดตั้งไลบรารีที่จำเป็น
pip install -r requirements.txt

# 4. (ทางเลือก) ทดสอบด้วยข้อมูลตัวอย่างก่อน
cp sample_data/*.xlsx data/      # Windows: copy sample_data\*.xlsx data\

# 5. รันแอป
streamlit run app.py
```

เปิดเบราว์เซอร์ไปที่ **http://localhost:8501** (เปิดอัตโนมัติอยู่แล้ว)

## 📥 การใช้งานกับข้อมูลจริง (29 ไฟล์)

1. ลบไฟล์ตัวอย่างออกจาก `data/` ถ้ามี
2. นำไฟล์ .xlsx รายเดือนจริงทั้ง 29 ไฟล์ (ม.ค. 2567 – พ.ค. 2569) มาวางไว้ใน `data/`
3. กดปุ่ม **🔄 รีเฟรชข้อมูล** ที่แถบด้านซ้ายของแอป
4. เมื่อมีไฟล์เดือนใหม่ในอนาคต วางไฟล์เพิ่มใน `data/` แล้วรีเฟรช — **ไม่ต้องแก้โค้ด**

ระบบใช้ "ลายเซ็นของโฟลเดอร์" (ชื่อไฟล์ + ขนาด + เวลาแก้ไข) เป็น cache key จึงโหลดข้อมูลใหม่เฉพาะตอนที่ไฟล์เปลี่ยนแปลงจริงเท่านั้น ทำให้เปิดแอปครั้งถัดไปเร็วขึ้นแม้มีข้อมูลหลายสิบไฟล์

## 🖥️ หน้าในแดชบอร์ด (8 หน้า)

| หน้า | เนื้อหา |
|---|---|
| 🏠 ภาพรวม | KPI หลัก, แนวโน้มรายได้, สัดส่วนสินค้า, insight เด่น |
| 📈 แนวโน้มรายได้ | รายได้/จำนวนบิล/มูลค่าเฉลี่ยรายเดือน, รายได้ตามวันในสัปดาห์ |
| 💳 การชำระเงิน | สัดส่วนและแนวโน้มวิธีชำระเงิน |
| 🧾 วิเคราะห์บิล | สถานะบิล, ประเภทการคิดราคา, เส้นทาง/สายกระจายที่ทำเงิน |
| ⏳ ลูกหนี้คงค้าง | ยอดค้างชำระ, บิลตัดจบ (ยังไม่รวม aging เพราะข้อมูลยังไม่มีวันครบกำหนด) |
| 👥 วิเคราะห์ลูกค้า | Pareto (80/20), การกระจุกตัวของรายได้ลูกค้า |
| 💡 Insight อัตโนมัติ | รวม insight จากทุกมิติในหน้าเดียว |
| 🩺 คุณภาพข้อมูล | แถวซ้ำ, ค่าผิดปกติ, วันที่แปลงไม่สำเร็จ พร้อมตัวอย่างแถวที่มีปัญหา |

ทุกตัวเลขและข้อความ insight **คำนวณสดจากไฟล์ในโฟลเดอร์ data/** — เมื่อเปลี่ยนไฟล์ ตัวเลขจะเปลี่ยนตามทันทีโดยไม่ต้องแก้โค้ด

## ⚠️ ข้อจำกัดที่ทราบอยู่แล้ว (สำหรับพัฒนาต่อ)

- ยังไม่มีข้อมูลต้นทุนเดินรถ/น้ำมัน/ระยะทาง จึงยังคำนวณ **Cost-to-Serve** หรือกำไรต่อเที่ยวไม่ได้
- ยังไม่มีคอลัมน์วันครบกำหนดชำระ จึงยังคำนวณ **Aging ของลูกหนี้** แบบเต็มรูปแบบไม่ได้ (ทำได้แค่นับบิลค้างชำระรวม)
- ตัวระบุลูกค้า (`ผู้รับ_encoded` / `ผู้ส่ง_encoded`) ถูกเข้ารหัสไว้แล้ว จึงบอกชื่อลูกค้าจริงไม่ได้ในแดชบอร์ดนี้ (เป็นไปตามข้อกำหนดด้านความลับของข้อมูล)

## 🛠️ แผนพัฒนาต่อ (ตาม Roadmap เดิม)

- เชื่อมข้อมูลใบรายการ/ต้นทุนเที่ยววิ่ง เพื่อวิเคราะห์กำไรต่อเส้นทาง
- เพิ่มการคำนวณ Aging ของลูกหนี้เมื่อมีข้อมูลวันครบกำหนดชำระ
- ทำเวอร์ชัน portfolio บน GitHub โดยใช้เฉพาะ `sample_data/` (ข้อมูลสุ่ม) เท่านั้น
