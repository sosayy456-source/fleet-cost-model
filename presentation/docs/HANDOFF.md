# HANDOFF — การส่งไม้ระหว่าง Claude กับ Codex

เจ้าของงานเป็นคนตัดสินใจและเป็นคนสั่งงานทั้งสองฝั่ง · agent ไม่คุยกันเอง คุยผ่านเอกสารในโฟลเดอร์นี้

| ใคร | หน้าที่ | เขียนไฟล์ไหนได้ |
|---|---|---|
| **Claude** | วางเรื่อง · storyboard · แผน · รีวิวงานของ Codex (เรื่องเล่า จังหวะ scroll แอนิเมชัน ความถูกต้องของตัวเลข) | `presentation/docs/*` เท่านั้น — **ไม่เขียนโค้ดเว็บ** |
| **Codex** | ลงมือเขียนเว็บตาม `IMPLEMENTATION_PLAN.md` + `STORYBOARD.md` | ทุกอย่างใน `presentation/` ยกเว้นแก้เนื้อหาแผนเอง (ขัดกับแผน = จดใน CHANGELOG ใต้ "รอเจ้าของงานตัดสิน") |

## กติกาการส่งไม้ (ทั้งสองฝั่ง)

จบงานแต่ละรอบ ต้องปิดท้ายคำตอบถึงเจ้าของงานด้วยบล็อกนี้ **และ** จดรอบนั้นลง `CHANGELOG.md`:

```
➡️ ขั้นต่อไป: ไปสั่ง <Claude | Codex>
สิ่งที่ต้องตัดสินก่อน (ถ้ามี): <คำถามถึงเจ้าของงาน — ไม่มีก็เขียน "ไม่มี">
ข้อความสั่งงาน (คัดลอกไปวางได้เลย):
> <ข้อความสั่งงาน 1–4 บรรทัด อ้างไฟล์/ฉาก/Phase ให้ชัด>
```

- ถ้างานรอบนั้นต้องให้เจ้าของงานดู/ตัดสินก่อน (เช่น ดูต้นแบบในเบราว์เซอร์) ให้บอกวิธีเปิดดู และให้ "ขั้นต่อไป" เป็นเจ้าของงานเอง
- ข้อความสั่งงานต้องอ่านเข้าใจได้โดยไม่ต้องรู้บทสนทนาก่อนหน้า — อ้างชื่อไฟล์ + หัวข้อแทน "ตามที่คุยกัน"

## วงรอบปกติ

```
เจ้าของงาน (ส่งลำดับเรื่อง/ความต้องการ)
   → Claude  แก้ STORYBOARD / IMPLEMENTATION_PLAN          → ส่งไม้ให้ Codex
   → Codex   ทำตามแผน · build ผ่าน · จด CHANGELOG           → ส่งไม้ให้ Claude รีวิว (หรือให้เจ้าของงานเปิดดู)
   → Claude  รีวิว · แก้แผน/เขียนรายการแก้ลง CHANGELOG      → ส่งไม้ให้ Codex
```
