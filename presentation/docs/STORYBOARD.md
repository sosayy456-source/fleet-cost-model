**ความต่อเนื่อง (สำคัญที่สุดของเรื่อง):** บิล 3 ใบที่ R1 สร้าง (ใบที่ 1 กรอกให้ดู อีก 2 ใบมีอยู่แล้ว) → R2 จัดเข้ารถคันเดียว ได้เลขที่ใบรายการ `[trip.docNo]` →
R3 คนขับเห็นใบนั้น → R4 บัญชีเปิดใบเดียวกัน · **เลขที่ใบรายการ/ทะเบียน/เส้นทางต้องตรงกันทุกฉาก** · ระหว่าง Role มี "เส้นใบรายการ" เล็ก ๆ
ที่มุมล่างของแผงคำอธิบายบอกสถานะเดินทางของเอกสาร: `บิล → รอจัดรถ → จัดรถแล้ว → จบงาน → ครบ 3 ฝ่าย` (ขั้นที่ผ่านแล้วติดสี accent)

**ทุก Role ขึ้นต้นเหมือนกัน:** กลับหน้าแรก (R0) → เมาส์คลิกการ์ด Role → ปุ่ม Continue → หน้าของฝ่ายเลื่อนเข้า ·
ตั้งแต่ Role ที่ 2 ไป ช่วงกลับหน้าแรกเป็นทางผ่านสั้น (ไม่ใช่ step)

## R0 · หน้าแรกของโมเดล (2 step)
- **R0.1** หน้าเลือกตำแหน่งเต็มจอ (ยังไม่มีแผงคำอธิบาย) · หัว "Select your role" · การ์ด 6 ตำแหน่งขึ้นทีละใบ (stagger)
  คำบรรยายลอยใต้: "ทุกคนเข้าโมเดลเดียวกัน — เห็นเมนูตามหน้าที่ของตัวเอง"
- **R0.2** Spotlight ไล่การ์ด 4 ฝ่ายที่จะพาดู (บริการลูกค้า → จัดรถ → คนขับ → บัญชี) แล้ว Admin · มีเลข ①②③④ + ⑤ บนการ์ดตามลำดับเรื่อง
  → เป็นสารบัญของทั้งการนำเสนอ

## R1 · ฝ่ายบริการลูกค้า (Customer Service) — บันทึกบิล (5 step)
- **R1.1 เข้าหน้า** เมาส์คลิกการ์ด "ฝ่ายบริการลูกค้า" → Continue → หน้า "บันทึกบิล" (Page switch)
  · แผง: **"รับงานจากลูกค้า แล้วบันทึกเป็นบิล"** — ไม่ต้องรู้ว่าจะไปรถคันไหน ระบบออกเลขที่บิลให้เอง
- **R1.2 อธิบายหน้า** หน้าจอว่าง · Spotlight ทีละกลุ่มช่อง (ผู้ส่ง/ผู้รับ → ต้นทาง/ปลายทาง → จำนวน/น้ำหนัก/ขนาด → เกณฑ์คิดราคา/ราคาต่อหน่วย)
  แต่ละกลุ่มมีป้ายสั้น 1 บรรทัดข้างช่อง (ทีละป้าย) · แผง: "กรอกเท่าที่ลูกค้าบอก ส่วนที่คำนวณได้ระบบคิดให้"
- **R1.3 กรอกข้อมูล** Type ทีละช่องตามลำดับหน้าจริง (ผู้ส่ง · ผู้รับ · Select ต้นทาง/ปลายทาง · จำนวน · น้ำหนัก · กว้าง ยาว สูง · Select เกณฑ์คิดราคา · ราคาต่อหน่วย)
  → Auto-calc "ปริมาตรรวม" และ "ราคารวม" นับขึ้นเมื่อช่องที่เกี่ยวข้องครบ · กล้องเลื่อนตามช่องที่กำลังกรอก
- **R1.4 ตรวจสอบก่อนบันทึก** เมาส์คลิก "ตรวจสอบก่อนบันทึก" → Modal หน้าสรุป (ตารางบิลตามหน้าจริง) → คลิกบันทึก →
  Number roll เลขที่บิล `[bills[0].no]` → Toast "บันทึกแล้ว · สถานะ รอจัดรถ" · แผง: "บิลขึ้นระบบกลาง ฝ่ายจัดรถเห็นทันที"
  · เส้นใบรายการ: "บิล ✓ → รอจัดรถ ●"
- **R1.5 กลับหน้าแรก** หน้าจอจำลองย่อลงกลับเป็นหน้า Select your role · การ์ด ① ติดเครื่องหมายถูก ② เริ่มเรืองแสง

## R2 · ฝ่ายจัดรถ (Fleet Coordinator) — รวมบิลเป็นใบรายการ (6 step)
- **R2.1 เข้าหน้า + คืออะไร** คลิกการ์ด "ฝ่ายเจ้าหน้าที่จัดรถ" → หน้า "จัดรถ" · แผง: **"รวมบิลที่ไปทางเดียวกันขึ้นรถคันเดียว ให้คุ้มที่สุด"**
  · Spotlight ตารางบิลรอจัดรถ (เห็นบิลที่ R1 เพิ่งสร้าง พร้อมบิลอื่น) และรูปรถ "สถานะการบรรทุก" ด้านขวา (ยังว่าง)
- **R2.2 เลือกรถ** Select ประเภทรถ → ชนิดรถ → ทะเบียน `[truck.plate]` (+ วันปล่อยรถ) · รูปรถด้านขวาเปลี่ยนเป็นรถชนิดนั้น ตู้ว่าง ขึ้นความจุ
  · แผง: "เลือกได้เฉพาะรถที่สถานะ ใช้งาน"
  > *ในแอปจริง ขั้นที่ 1 = เลือกบิล ขั้นที่ 2 = เลือกรถ แต่เลือกรถก่อนได้ — เรื่องนี้เลือกรถก่อน (ตามบทเจ้าของงาน) เพื่อให้เห็นตู้เติมตอนติ๊กบิล*
- **R2.3 เลือกบิลเข้ารถ + แนะนำตามเส้นทาง** Check บิลแรก (บิลของ R1) → ตารางล็อกเส้นทาง: บิลที่ต้นทางเดียวกันและปลายทางอยู่ "ระหว่างทาง" ยังเลือกได้
  บิลอื่นจาง · ป้าย "เลือกทุกบิลที่ไปทางเดียวกัน" · Check อีก 2 ใบ · ตู้รถเติมเหลืองตามบิล หลอด Load Factor นับขึ้น `[dispatch.lf]`
  · แผง: **"ระบบแนะนำบิลที่ไปทางเดียวกัน — ตามจุดที่รถวิ่งผ่าน"**
- **R2.4 ส่วนที่ 2: กำไรเที่ยวนี้** กล้องซูมกล่องสรุป · Auto-calc รายได้ (รวมทุกบิล) → ต้นทุนพยากรณ์ → กำไร (ประมาณการ) กรอบเขียว/แดง
  · แผง: "รู้ก่อนรถออกว่าเที่ยวนี้กำไรหรือขาดทุน"
- **R2.5 ต้นทุนพยากรณ์มาจากไหน** "รายละเอียดต้นทุนพยากรณ์" กางลง แท่งแต่ละกลุ่มยืดทีละแถว (ชื่อกลุ่มตาม `COST_PART_LABELS`)
  · แผง: "ค่าเฉลี่ยต้นทุนจริงของเส้นทาง × ชนิดรถนี้ จากข้อมูลย้อนหลัง"
- **R2.6 ยืนยันการจัดรถ** คลิก "ยืนยันการจัดรถ" → Number roll เลขที่ใบรายการ `[trip.docNo]` ใหญ่กลางจอ → บิลทั้ง 3 เปลี่ยนสถานะ "จัดรถแล้ว"
  · เส้นใบรายการ: "จัดรถแล้ว ●" · กลับหน้าแรก (ทางผ่าน)

## R3 · คนขับ (Driver) — จบงาน (4 step)
- **R3.1 เข้าหน้า + คืออะไร** คลิกการ์ด "คนขับ" → หน้า "เที่ยวรถของฉัน" · แผง: **"จัดรถเสร็จ เที่ยวจะมาอยู่ที่นี่ — เห็นทั้งงานที่กำลังวิ่งและงานที่รอออกเดินทาง"**
- **R3.2 ค้นหาทะเบียน** Type เลขท้ายทะเบียนในช่อง "ค้นหาทะเบียน — พิมพ์เลขท้ายก็ได้" → รายการกรองเหลือรถ `[truck.plate]` → คลิกเลือก ·
  การ์ดงานขึ้น: เลขที่ใบรายการ `[trip.docNo]` · เส้นทาง · ระยะทาง · แผง: "คนขับเลือกรถที่ตัวเองขับ ไม่ต้องจำเลขเอกสาร"
- **R3.3 แนบรูปไมล์** คลิก "📷 แนบรูปไมล์หลังเสร็จงาน" → ภาพไมล์จำลองเด้งเข้ากรอบเล็ก → ปุ่มเปลี่ยนเป็น "✓ แนบรูปไมล์หลังเสร็จงานแล้ว"
  · แผง: "ต้องแนบรูปไมล์ก่อนจึงกดจบงานได้"
- **R3.4 จบงาน** คลิก "จบงาน" → Toast "บันทึกจบงานแล้ว" · การ์ดงานย้ายออกจาก "งานที่กำลังวิ่ง" · เส้นใบรายการ: "จบงาน ●" · กลับหน้าแรก

## R4 · ฝ่ายบัญชี (Accounting) — ต้นทุนจริง (5 step)
- **R4.1 เห็นเลขที่ใบรายการ** คลิกการ์ด "ฝ่ายบัญชีการเงิน" → หน้า "ใบที่ยังไม่ครบ" → แถว `[trip.docNo]` ติดป้ายขาดฝ่ายบัญชี → คลิกเปิด
  · แผง: **"ทุกเที่ยวที่วิ่งจบแล้วแต่ยังไม่มีต้นทุน มารออยู่ที่นี่"**
- **R4.2 กรอกบิลน้ำมัน + เทียบมาตรฐาน** ตารางบิลน้ำมัน: "+ เพิ่มบิล" แล้ว Type ทีละแถว (วันที่ · ปั๊ม · ประเภท · วิธีจ่าย · ลิตร · จำนวนเงิน) 2–3 แถว →
  กล่อง "เทียบต้นทุนมาตรฐาน" Auto-calc: จริงตามบิล vs มาตรฐาน → **ผลต่างเป็นสีแดง** + ป้าย "เกินมาตรฐาน `[fuel.over]` บาท — ควรตรวจสอบ"
  · แผง: "ระบบคิดค่าน้ำมันมาตรฐานจากระยะทาง × อัตราสิ้นเปลือง ถ้าจ่ายจริงเกิน ให้ตรวจสอบ"
- **R4.3 กรอกต่อให้ครบ** กล้องเลื่อนลงช่องต้นทุนที่เหลือ (เบี้ยเลี้ยง · ค่าธรรมเนียม ฯลฯ ตามหน้าจริง) — **ตัวเลขขึ้นทีเดียวทั้งช่อง** (ไม่ Type ทีละตัว — เร็ว)
  · แผง: "กรอกครั้งเดียวต่อเที่ยว"
- **R4.4 ส่วนสรุป: รายได้ · ต้นทุน · กำไร** กล้องซูมส่วนสรุปของฟอร์ม (ชื่อส่วนตามหน้าจริง) · รายได้ → ต้นทุนจริง → กำไรจริง นับขึ้น ·
  ข้าง ๆ แถบเล็ก "เทียบพยากรณ์ตอนจัดรถ" (จาก R2.4) ให้เห็นว่าจริงต่างจากคาดเท่าไร
- **R4.5 บันทึก** คลิกบันทึก → Toast · ป้าย "ครบ 3 ฝ่าย" · เส้นใบรายการครบทุกขั้น (ติดสีทั้งเส้น) · แผง: "ใบนี้พร้อมเข้า dashboard แล้ว"

## A0 · Admin — เข้าสู่ Executive Dashboard (1 step)
- **A0.1** กลับหน้าแรก → คลิกการ์ด "ผู้ดูแลระบบ" → หน้า Executive Dashboard เลื่อนเข้า (ย่อความจากหน้าจริง: การ์ดหัว + การ์ดเด่นแถวแรก)
  · แผง: **"ข้อมูลที่ 4 ฝ่ายกรอก รวมเป็นภาพของทั้งบริษัท — ดู 2 เรื่องที่เด่นที่สุด"** · ป้าย ① ② ชี้เมนูที่จะไป

## A1 · จุดเด่น 1: การใช้ประโยชน์กองรถ (3 step)
- **A1.1 สถานะรถล่าสุด** หน้า "สถานะกองรถ": การ์ดนับ พร้อมใช้งาน `[fleet.ready]` · กำลังเดินทาง `[fleet.moving]` · ไม่พร้อมใช้งาน `[fleet.down]` นับขึ้น ·
  แผนที่ย่อ (จุดรถตาม ต้นทาง→ปลายทาง ของเที่ยวล่าสุด) จุดกระพริบเบา ๆ · รถของเที่ยวสมมติ (`[truck.plate]`) มีป้ายชื่อ
  · แผง: **"สถานะรถล่าสุด"** — "รู้ทันทีว่ามีรถว่างกี่คัน คันไหนกำลังวิ่ง จากข้อมูลที่ฝ่ายจัดรถและคนขับกด" (**ห้ามใช้คำว่า real-time / GPS**)
- **A1.2 Load Factor ตอนนี้** ตู้รถใหญ่ เติมถึง `[lf.avg]` ส่วนว่างเป็นแดง · ตัวเลข "ต้นทุนที่จมกับที่ว่าง `[lf.idle]` บาท" · แผง: "จ่ายเต็มคัน แต่ขนไม่เต็ม"
- **A1.3 ถ้า Load Factor เพิ่มได้** ตัวเลื่อน (ตามส่วน "จำลองผล" ของแท็บ) เลื่อนเอง +5% → +10% · ส่วนแดงหดลง ·
  **"ต้นทุนที่จมลดลง `[lf.sim[].saved]` บาท"** นับขึ้นตามตัวเลื่อน · แผง: "เพิ่ม Load Factor ได้เท่านี้ ต้นทุนที่จมลดลงเท่านี้"

## A2 · จุดเด่น 2: Manager Dashboard รายสาขา (3 step)
- **A2.1 ผลรายวันของแต่ละสาขา** คลิกเมนู "Manager Dashboard" → ตารางสรุปรายสาขาของ `[manager.date]`: ออกกี่เที่ยว · เที่ยวกำไรดี · เที่ยวขาดทุน
  แถวขึ้นทีละสาขา · แผง: **"ผู้จัดการแต่ละสาขารู้ผลของเมื่อวานได้ทุกเช้า"**
- **A2.2 เที่ยวขาดทุน** Spotlight คอลัมน์เที่ยวขาดทุน สาขาที่มากสุดเป็นแดง · กดแถว → รายการเที่ยวขาดทุนของสาขานั้นกางลง (2–3 แถว)
- **A2.3 ของลืมส่ง · ส่งช้า** การ์ด 2 ใบ: ของตกค้าง/ลืมส่งลูกค้า `[manager.forgotten]` · บิลที่ส่งล่าช้า `[manager.late]` + ตารางย่อ 3 แถว
  · แผง: "ปัญหาบริการที่ลูกค้าเห็น — ตามแก้ได้รายสาขา"
  > ตาราง "ส่งช้า" และ "ของตกค้าง/ลืมส่ง" มีในแอปแต่ซ่อนอยู่ (`SHOW_TABS = false`) — เว็บนำเสนอโชว์ได้ตามที่เจ้าของงานสั่ง
