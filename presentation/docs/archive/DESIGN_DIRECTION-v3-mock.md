> v2 เก็บไว้ที่ `archive/DESIGN_DIRECTION-v2-pulse.md` เป็นประวัติ ห้ามนำกลับมาใช้โดยไม่ถาม

## 1. แก่น

- **นำเสนอตัวโมเดลเป็นหลัก** — ผู้ชมเห็นหน้าจอของแอปจริง (ธีมเดียวกัน) ถูกใช้งานทีละฝ่าย ตั้งแต่หน้าแรกจนได้ dashboard
- **ทุก step = หนึ่งการกระทำบนหน้าจอ** (คลิก · พิมพ์ · เลือก · บันทึก) พร้อมคำอธิบายสั้น ๆ ว่าทำอะไร ทำไม
- **เนียนเหมือนวิดีโอสาธิต** — เมาส์จำลองเคลื่อนไปคลิก ตัวหนังสือพิมพ์ขึ้นในช่อง ตัวเลขคำนวณเอง กล้องซูมไปส่วนที่กำลังพูด
- **เที่ยวสมมติเที่ยวเดียววิ่งทั้งเรื่อง** — บิลที่ Role 1 สร้าง ถูกจัดรถใน Role 2 · ใบรายการเดียวกันขึ้นหน้าคนขับ (Role 3) และบัญชี (Role 4)
- ส่วนผู้ดูแลระบบ (Admin) โชว์แค่ **จุดเด่น 2 เรื่อง** ไม่พาเดินทั้ง dashboard

## 3. โครงจอ (ทุกฉาก Role ใช้โครงเดียวกัน)

```
┌──────────────────────────────────────────────────────────────────────────┐
│  แถบบนบาง: ชิป Role ปัจจุบัน (สี accent) · ขั้น 1–5 ของ Role · ปุ่มพรีเซนเตอร์      │
├──────────────────────┬───────────────────────────────────────────────────┤
│ แผงคำอธิบาย (34%)     │  หน้าจอจำลองของแอป (66%)                               │
│  ROLE 2 · จัดรถ       │  ┌ กรอบหน้าต่างเบราว์เซอร์ (มุมมน เงาฟุ้ง) ───────────┐  │
│  ขั้น 3 / 5           │  │ แถบเมนูซ้ายชมพู │ หน้าของ Role นั้น                │  │
│  เลือกบิลเข้ารถ        │  │                 │  [ช่องที่กำลังพูดมีกรอบเรืองแสง]  │  │
│  (พาดหัว 40–48px)      │  │                 │           ↖ เมาส์จำลอง          │  │
│  คำอธิบาย ≤ 3 บรรทัด  │  └──────────────────────────────────────────────┘  │
│  (22–24px)            │                                                   │
└──────────────────────┴───────────────────────────────────────────────────┘
```

- แผงคำอธิบายเปลี่ยนตาม step: ข้อความเก่าเลื่อนขึ้น+จาง ข้อความใหม่เลื่อนเข้า (y 24px) · มีตัวเลข "ขั้น x / y" ของ Role
- หน้าจอจำลองขนาดอ้างอิง **1440×900** วาดครั้งเดียว ย่อด้วย `transform: scale()` ให้พอดีกรอบ · **กล้อง** = scale+translate ของหน้าจอจำลอง
- ช่วงเปิด Role (ขั้นแรก) แผงคำอธิบายกว้างเต็มจอชั่วครู่ (ชื่อฝ่าย + หน้าที่) แล้วหดเข้าซ้ายเมื่อหน้าจอจำลองเลื่อนเข้า

## 4. ชุดท่า (primitive) — ใช้ซ้ำทั้งเรื่อง

| ชื่อ | ท่า | หมายเหตุ |
|---|---|---|
| **Cursor** | เมาส์จำลอง (SVG ลูกศร) เคลื่อนไปยังกลางของ element เป้าหมาย (power2.inOut · 0.6–0.9 วิ) แล้ว "คลิก" = วงกระเพื่อมสี accent + ปุ่มยุบ 2% | หาเป้าจาก `data-target="..."` ในหน้าจำลอง |
| **Type** | ตัวหนังสือในช่องกรอกขึ้นทีละตัว **ผูกกับ scroll** (เลื่อนกลับ = ลบกลับ) + เคอร์เซอร์กะพริบท้ายข้อความ | ช่องตัวเลขพิมพ์เป็นตัวเลขดิบ แล้วจัดรูปแบบ (มีจุลภาค) เมื่อพิมพ์ครบ |
| **Select** | dropdown กางลง (scaleY จากบน) → แถวที่เลือกไฮไลต์ → หุบ ค่าใหม่เฟดเข้า | |
| **Check** | ติ๊กบิล: ช่องติ๊กเด้ง แถวพื้นเป็น accent อ่อน | |
| **Auto-calc** | ค่าที่ระบบคิดให้ (ปริมาตร · ราคารวม · Load Factor · ยอดรวม) นับขึ้นจากค่าเดิมไปค่าใหม่ พร้อมขีดเส้นใต้กะพริบ 1 ครั้ง | บอกผู้ชมว่า "ระบบคิดให้" |
| **Spotlight** | ส่วนที่กำลังพูดมีกรอบ accent 2px เรืองแสงจาง ส่วนอื่นของหน้าจอจำลองจางลง 35% | ห้าม blur |
| **Camera** | ซูมหน้าจอจำลองไปส่วนที่พูด (scale 1.3–1.8) และถอยกลับ (power3.inOut · ยาวเท่ากับช่วง scroll) | |
| **Modal / Toast** | ป็อบอัพสรุป/ยืนยัน ขยายจาก 0.96 + เฟด · Toast เลื่อนจากขวาบน "บันทึกแล้ว · สถานะ รอจัดรถ" | |
| **Number roll** | เลขที่ใบรายการ/เลขที่บิล 13 หลักหมุนแบบ slot ทีละหลักจากซ้ายไปขวาแล้วหยุด | ใช้ตอนระบบออกเลข |
| **Page switch** | เปลี่ยนหน้าในแอปจำลอง: เมนูซ้ายไฮไลต์เลื่อน · เนื้อหาเก่าเฟดออก เนื้อหาใหม่เลื่อนขึ้น 16px | |

กติกา: ทุกท่าใช้ transform / opacity / stroke-dashoffset · ท่าทุกตัว **ผูกกับ scroll (scrub)** ยกเว้นเคอร์เซอร์กะพริบ ·
หนึ่ง step มีการกระทำหลักอย่างเดียว · ระยะเวลาของ step ≈ 100–150vh ของการเลื่อน

## 5. สิ่งที่ห้าม

- ห้ามโชว์ข้อมูลจริงในเที่ยวสมมติ (ชื่อลูกค้า · ทะเบียน · เลขเอกสาร ต้องเป็นของสมมติที่ดูออกว่าสมมติ)
- ห้ามอ้างความสามารถที่แอปไม่มี — ตำแหน่งรถพูดว่า **"สถานะรถล่าสุด"** ไม่ใช่ real-time/GPS · Load Factor พูดว่า **"ต้นทุนที่จมลดลง"** ไม่ใช่ "กำไรเพิ่ม" ·
  คนขับแนบ **รูปไมล์** (ตามแอป) ไม่ใช่รูปบิลน้ำมัน (เจ้าของงานเลือกทั้งสามข้อ 25 ก.ย. 2569)
- ห้ามคำอธิบายยาวเกิน 3 บรรทัดต่อ step · ห้ามป้ายอธิบายลอยทับหน้าจอจำลองเกิน 1 ป้ายพร้อมกัน
- ห้ามแต่งหน้าจอจำลองให้ต่างจากแอปจริง (ลำดับช่อง · ชื่อปุ่ม · ชื่อส่วน ต้องตรง) — ยกเว้นตัดรายละเอียดที่ไม่ได้พูดถึงให้โล่ง
