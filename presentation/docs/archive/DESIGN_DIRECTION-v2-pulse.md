# DESIGN DIRECTION — "Dashboard เป็นตัวละคร ไม่ใช่หน้าเว็บ"

> เจ้าของงานสั่ง 25 ก.ย. 2569 · อ้างอิง: Framer Pulse (https://ambiguous-surprise-609016.framer.app/) · Webflow dashboard showcase (Dashly X / Dashbrd X) ·
> Dashboard Kit · หน้า product ของ Apple · **ไฟล์นี้ทับ PRESENTATION_BRIEF ข้อ 6 (โทเคนหน้าตา) ทุกจุดที่ขัดกัน**

---

## 1. แก่นของสไตล์

เจ้าของงานชอบ dashboard ที่ดู **modern · clean** แต่ **ไม่เอา dashboard ทั้งหน้ามาโชว์ทีเดียว**
และอยากได้ตัวหนังสือสวย อ่านง่าย แบบหน้า product ของ Apple → หลัก 5 ข้อ:

1. **หนึ่งจอ หนึ่งความคิด** (Apple) — ประโยคพาดหัวใหญ่ + ของเด่นชิ้นเดียว · ไม่มีจอไหนมีกราฟเกิน 1 ตัวพร้อมกัน
2. **Dashboard เป็นตัวละครที่ถูกเปิดทีละส่วน** — มีกรอบ dashboard ตัวเดียวทั้งเรื่อง กล้องซูมเข้าไปทีละ widget
   ส่วนที่ยังไม่ถึงคิวเป็นโครงเทาจาง (skeleton) · **เห็น dashboard เต็มหน้าแค่ครั้งเดียวตอนปิดองก์** (เป็นรางวัลของผู้ชม)
3. **เทาก่อน แล้วค่อยมีสี** (Pulse) — กราฟขึ้นมาเป็นเทาทั้งหมดก่อน แล้ว "จุดที่เป็น insight" ค่อยติดสีเน้น ·
   สีเน้นมีแค่สีเดียวต่อจอ ตาผู้ชมจึงไปที่จุดเดียวที่ผู้นำเสนอกำลังพูด
4. **KPI ลอยออกมาจาก dashboard** — ตัวเลขสำคัญหลุดออกจากกรอบเป็นการ์ดเล็กลอย (floating chip) แล้วขยายมากลางจอ
5. **ทุก insight จบด้วยประโยคเดียว** — ประโยคสรุปที่มีคำสำคัญอยู่ในแถบไฮไลต์ (เหมือน "real time." ของ Pulse)

## 2. สิ่งที่เรียนจากหน้าอ้างอิง (Pulse — วัดจากหน้าจริง)

| สิ่งที่เห็น | ค่าที่วัด/สังเกต | เอามาใช้ยังไง |
|---|---|---|
| พื้นหลัง | ขาวอมครีม `#FAFAF6` + แสงฟุ้งสีเน้นจาง ๆ มุมจอ | พื้นหลังหลัก · แสงฟุ้งเฉพาะปก/จุดไคลแมกซ์ |
| หมึก | ดำอมเขียว `#12120E` | สีตัวหนังสือหลัก |
| พาดหัว | Space Grotesk 700 · 76px · letter-spacing −3% (−2.28px) | พาดหัวใหญ่ ตัวชิด (ดูข้อ 4 ฟอนต์ไทย) |
| ป้ายเหนือพาดหัว (eyebrow) | ● + ตัวพิมพ์ใหญ่ monospace เว้นระยะกว้าง "PRODUCT ANALYTICS, REAL TIME" | ป้ายบอกองก์/หมวด ทุกฉาก |
| คำเน้นในพาดหัว | พื้นสีเน้นทรงแคปซูลหลังคำ "real time." | คำสำคัญหนึ่งคำต่อพาดหัว |
| กรอบ dashboard | การ์ดขาว ขอบ 1px เทาอ่อน มุมมน ~16px เงาฟุ้งมาก ๆ จาง ๆ | `DashFrame` ตัวละครหลัก |
| การ์ด KPI | ป้าย mono ตัวเล็ก + ตัวเลขใหญ่ + delta สีเน้นตัวเล็ก ("72% +4.2%") | `KpiChip` |
| widget ลอย | การ์ดเล็กวางคร่อมขอบกรอบ dashboard ("RETENTION · WOW +18%") มี parallax | ท่า "KPI หลุดออกจากกรอบ" |
| กราฟแท่ง | แท่งเทาทั้งหมด มีแค่ 3–4 แท่งที่เป็นสีเน้น | ท่า "เทาก่อน แล้วค่อยมีสี" |
| การ์ดความสามารถ | รางการ์ดแนวนอน เลื่อนตาม scroll + แถบความคืบหน้า "02 ─── 04" | ท่ารางแนวนอน (ข้อ 5 · B6) |
| ปุ่ม/ชิป | ทรงแคปซูล ดำทึบ/ขอบบาง | ปุ่มพรีเซนเตอร์ · ชิปสถานะ |

ของ Apple: พาดหัวใหญ่มาก 1–2 บรรทัด · ข้อความรองสีเทาสั้น ๆ · พื้นที่ว่างเยอะ · ภาพ/ตัวเลขขยับตาม scroll แบบค้างจอ (sticky)

## 3. โทเคนสี

| โทเคน | ค่า | ใช้กับ |
|---|---|---|
| `--bg` | `#FAFAF6` | พื้นหลังทั้งเว็บ |
| `--surface` | `#FFFFFF` | การ์ด · กรอบ dashboard |
| `--line` | `#E7E7E1` | ขอบ 1px · เส้นกริด |
| `--skeleton` | `#EDEDE7` | กราฟ/แท่งที่ยังไม่ถึงคิว · widget ที่ยังไม่เปิด |
| `--ink` | `#12120E` | ตัวหนังสือหลัก |
| `--ink-2` | `#5F5F58` | ข้อความรอง |
| `--ink-3` | `#9A9A92` | ป้าย mono · หน่วย |
| `--accent` | `#C6F432` (เขียวมะนาว) | **สีเน้นสีเดียว** = "insight / ดี / จุดที่กำลังพูด" · พื้นแคปซูลคำเน้น |
| `--accent-ink` | `#3F5A00` | ตัวหนังสือบนพื้น accent / ตัวเลข delta บวก |
| `--leak` | `#E5484D` | **เงินรั่ว / ขาดทุน / เกินเกณฑ์** — ใช้แทน accent ในฉากที่พูดเรื่องเสีย |
| `--warn` | `#F5A524` | เหลืองของ PI เท่านั้น |

- จอหนึ่งมี accent **หรือ** leak อย่างใดอย่างหนึ่งเป็นหลัก ไม่ใช้คู่กันเป็นสีเด่น (ยกเว้นกราฟ กำไร/ขาดทุน)
- **สีหมวด PI 5 สีเดิมเลิกใช้เป็นพื้นไล่สี** — เหลือเป็นจุดสีเล็ก ๆ หน้าชื่อหมวดเท่านั้น (ให้ผู้ชมที่เคยเห็นแอปจำได้) ·
  วงแหวน PI ใช้เทา → accent ตามลำดับที่เปิด (ข้อ 5 · B3)
- เจ้าของงานเปลี่ยนสีเน้นได้ที่โทเคนเดียว (`--accent`) — ค่าตั้งต้นตาม Pulse

## 4. ตัวอักษร (ต้องอยู่ในเครื่อง ไม่พึ่งเน็ต)

ฟอนต์ของหน้าอ้างอิง (Space Grotesk) **ไม่มีตัวไทย** — ต้องจับคู่ ไทย + ละติน/ตัวเลข + mono

| บทบาท | ข้อเสนอ (ค่าตั้งต้น) | ทางเลือก | เหตุผล |
|---|---|---|---|
| ไทย พาดหัว+เนื้อความ | **Anuphan** (Cadson Demak · OFL) | LINE Seed Sans TH (ของเดิม) · IBM Plex Sans Thai | ไทยไม่มีหัว ทันสมัย เส้นเรียบ ใกล้ความรู้สึก Apple · มีตัวละตินในชุด |
| ตัวเลขใหญ่ / ละติน | **Inter** (OFL · มี `tnum`) | Space Grotesk (ตามอ้างอิง) | ตัวเลขกว้างเท่ากัน → นับขึ้นแล้วไม่สั่น (LINE Seed ไม่มี tnum) |
| ป้าย eyebrow / หน่วย / ป้ายกราฟ | **JetBrains Mono** (OFL) | IBM Plex Mono | ให้กลิ่น "dashboard" แบบ Pulse |

- **ต้นแบบต้องมีหน้าเทียบฟอนต์** (`?fonts`) — พาดหัว/ตัวเลข/ป้ายเดียวกันใน 3 ชุดไทย ให้เจ้าของงานเลือกด้วยตา
- ดาวน์โหลด woff2 เก็บใน `src/assets/fonts/` (subset ไทย + ละติน) พร้อมไฟล์สัญญาอนุญาต · งบฟอนต์รวม ≤ 400 KB
- ขนาด (ที่ 1920×1080 · ใช้ `clamp()` ย่อตามจอ):
  - พาดหัวฉาก **72–96px** น้ำหนัก 700 · letter-spacing −2% (ไทยอย่าติดลบเกิน −1% สระบนจะชนกัน)
  - ตัวเลข KPI พระเอก **120–180px** Inter 600–700 `tnum` · letter-spacing −3%
  - ข้อความรอง **24–28px** สี `--ink-2` · ความยาว ≤ 2 บรรทัด
  - ป้าย mono **14–16px** ตัวใหญ่ letter-spacing +12% สี `--ink-3` (ป้ายที่ผู้ชมไม่จำเป็นต้องอ่านจึงเล็กได้)
  - ทุกอย่างที่ต้องอ่าน ≥ 18px (กติกาจอเดิม)

## 5. ชุดท่า (beat) ที่ใช้ซ้ำทั้งเรื่อง

ทุกฉากประกอบจาก beat พวกนี้ · STORYBOARD อ้างชื่อ beat แทนการเขียนท่าใหม่ทุกครั้ง

| beat | ชื่อ | ท่า | ใช้เมื่อ |
|---|---|---|---|
| **B1** | Statement | eyebrow mono → พาดหัวขึ้นทีละบรรทัด (y 40→0 · opacity) → แคปซูล accent ขยายจากซ้ายไปขวาหลังคำเน้น (scaleX 0→1) | เปิดทุกฉาก · คำถามที่ผู้ชมมีในหัว |
| **B2** | KPI pop | การ์ด KPI หลุดจากตำแหน่งใน `DashFrame` บินมากลางจอพร้อมขยาย (FLIP ด้วย transform) → ตัวเลขนับขึ้น → ชิป delta เด้ง | ตัวเลขพระเอกของฉาก |
| **B3** | Gray → Insight | กราฟขึ้นเป็น `--skeleton` ทั้งหมด → หยุด 1 step → เฉพาะแท่ง/เส้น/ส่วนที่เป็น insight เปลี่ยนเป็น accent/leak + เส้นชี้ + ป้ายตัวเลข | กราฟทุกตัว |
| **B4** | Floating widgets | การ์ดเล็ก 2–3 ใบลอยคร่อมขอบ `DashFrame` ขยับ parallax ต่างความเร็วกัน (y ±40px ตาม p) | ปก · ช่วงเปลี่ยนองก์ |
| **B5** | Camera | `DashFrame` ทั้งกรอบ scale+translate ให้ widget ที่ต้องการเต็มจอ · widget อื่นจางเป็น 0.25 (ห้าม blur) | เข้า/ออกแต่ละ widget ในองก์ III |
| **B6** | Horizontal rail | ฉากค้าง การ์ดเรียงแนวนอนเลื่อนจากขวาไปซ้ายตาม scroll + แถบ "02 ─── 04" | รายการ 3–5 ข้อ (ขั้นงาน 3 ฝ่าย · 4 มุมมอง) |
| **B7** | Sticky split | ข้อความซ้ายเปลี่ยนตาม step (เก่าจางขึ้น ใหม่เลื่อนเข้า) · ภาพขวาค้างและเปลี่ยนสถานะตาม step | อธิบายทีละขั้น (โครงต้นทุน · สูตร) |
| **B8** | Insight line | ประโยคสรุปหนึ่งบรรทัดใต้กราฟ คำสำคัญในแคปซูล accent/leak · ขึ้นหลัง B3 เสมอ | ปิดทุกฉากในองก์ III |
| **B9** | Pull-back reveal | กล้องถอยจาก widget สุดท้ายจนเห็น `DashFrame` ทั้งหน้า ทุก widget เปิดสีครบ · floating widgets ลอยเข้าประกอบรอบกรอบ | **ครั้งเดียว** ตอนจบองก์ III |

กติกาการเคลื่อนไหว: easing `power3.out` สำหรับของที่เข้า · `power2.inOut` สำหรับกล้อง · ระยะเคลื่อน ≤ 60px ยกเว้นกล้อง ·
ไม่มีเด้ง (elastic/back) ยกเว้นชิป delta · ทุกอย่างยังเป็น transform/opacity/stroke-dashoffset ตามกติกาเดิม

## 6. `DashFrame` — dashboard ตัวละครหลัก

- **ไม่ใช่ภาพหน้าจอ** — เป็น component SVG/HTML ที่วาดเลียนแบบหน้า Executive Dashboard ของแอปหลักแบบย่อความ (ตัดรายละเอียดทิ้ง เหลือโครง)
  เพื่อให้กล้องซูม และเปิด widget ทีละตัวได้ · ภาพหน้าจอจริง (ข้อ 6.1 ของแผน) ยังใช้ตามเดิมเป็น "หลักฐานว่าระบบมีจริง"
- โครง: แถบข้างซ้ายบาง (ไอคอน 5 ตัว) · แถวบน KPI 4 ใบ · กลางซ้าย กราฟรายเดือน · กลางขวา แผนที่ย่อ/จัดอันดับเส้นทาง ·
  ล่าง แถบ Load Factor · มุมขวาล่าง วงแหวน PI
- ทุก widget มี 3 สถานะ: `skeleton` (เทาไม่มีตัวเลข) → `gray` (มีโครงข้อมูลเป็นเทา) → `live` (ติดสี มีตัวเลข) · ฉากสั่งสถานะผ่าน props
- ขนาดอ้างอิง 1440×900 วาดครั้งเดียว ซูมด้วย transform (ห้ามวาดใหม่ตามขนาด)

## 7. สิ่งที่ห้าม (ทำให้หลุดจากสไตล์)

- ห้ามโชว์ dashboard ครบทุก widget ติดสีพร้อมกัน ก่อน B9
- ห้ามพื้นไล่สีเข้มเต็มการ์ด (แบบ `.pi-box` ของแอปหลัก) — ขัดกับความ clean
- ห้ามกราฟหลายสีพร้อมกันเกิน 3 สี (เทา + accent + leak)
- ห้ามเงาเข้ม/ขอบหนา · ห้ามไอคอนอีโมจิบนจอ
- ห้ามข้อความอธิบายยาวบนจอ — ≤ 2 บรรทัดต่อ step ที่เหลือเป็นหน้าที่ผู้นำเสนอ (โน้ตในโหมด `P`)
