# เดินชมโมเดลต้นทุนการเดินรถ · v3

Phase V1 มี R0 เลือกหน้าที่ 2 ขั้น และ R1 ฝ่ายบริการลูกค้า 5 ขั้น ใช้บิลสมมติสามใบ เล่าเฉพาะการสร้างบิลแรก อีกสองใบเตรียมไว้สำหรับ Phase V2

## เปิดดู

```powershell
cd presentation
npm.cmd ci
npm.cmd run build
npm.cmd run preview
```

เปิด URL ที่แสดง ปกติคือ `http://127.0.0.1:4173/` หรือดับเบิลคลิก `dist/index.html` เพื่อเปิดออฟไลน์ สคริปต์ สไตล์ ฟอนต์ และข้อมูลฝังไว้แล้ว เก็บ `dist/OFL.txt` คู่กันเมื่อส่งต่อ

- เลื่อนเมาส์ควบคุมการพิมพ์และกล้อง; เลื่อนกลับเพื่อลบข้อความย้อนกลับ
- `→` / `Space` / `PageDown` ไปขั้นถัดไป; `←` / `PageUp` ย้อนขั้น
- `Home` / `End` ไปต้น/ท้าย; `1` / `2` เลือกฉาก; `P` เปิดโน้ต; `F` เต็มจอ
- `?lite` หรือการตั้งค่าลดการเคลื่อนไหว แสดงสถานะปลายขั้นทันที ครบทั้ง 7 ขั้น ไม่มีเมาส์จำลอง
- URL เช่น `#r1-3` กลับมาขั้นเดิมได้เมื่อรีเฟรช
- `Ctrl+C` ในหน้าต่างคำสั่งเพื่อปิดเซิร์ฟเวอร์

## ข้อมูลและการตรวจ

แก้ข้อมูลสมมติใน `tools/scenario.input.json` แล้วรัน `npm.cmd run scenario` ด้วย Node 22.18+ หรือ 24 สคริปต์ import `billVolume`, `billTotalOf` และรูปแบบปีเดือนจากแอปจริง แล้วสร้าง `src/data/scenario.json` แบบทำซ้ำได้ ไม่มีสูตรธุรกิจหรือการเรียกแอปหลักตอนเปิดเว็บ

`npm.cmd test` ตรวจสูตร ตัวเลข เลขเอกสาร และการนำทาง; `npm.cmd run build` ตรวจ TypeScript งบขนาด และออฟไลน์

ทดสอบเบราว์เซอร์ด้วย Playwright/Chromium ที่ติดตั้งแยกไว้:

```powershell
node tools/check-presentation.mjs <พาธ-playwright/index.mjs> <พาธ-chrome.exe>
```

ผลกับภาพอยู่ใน `qa/v3/` ซึ่งไม่เข้า Git ตรวจสองขนาดจอ การย้อนขั้น hash รีเฟรช เปลี่ยนขนาด โหมด lite/reduced-motion และเปิดไฟล์โดยปิดเครือข่าย

## เทียบกับแอปจริงแบบอ่านอย่างเดียว

`npm.cmd run reference` เปิดซอร์ส `app/` ที่ `http://127.0.0.1:5174/fleet-cost-model/` ด้วย config ใน `presentation/tools/` ปิดปลั๊กอิน ETL และเก็บแคชเฉพาะ `presentation/qa/` เพื่อไม่เขียนไฟล์ในแอป ใช้ข้อมูล sample

`node tools/capture-reference.mjs <พาธ-playwright/index.mjs> <พาธ-chrome.exe>` เก็บภาพหน้าเลือกหน้าที่และบิล บล็อกคำขอเขียนและบริการภายนอก ไม่กดบันทึก

หน้าจำลองเล่าเส้นทางที่เชื่อมระบบกลางสำเร็จ จึงไม่มีคำเตือนว่าไม่ได้เชื่อมชีต ส่วนเลขบิลขนาดใหญ่และ Toast เป็นคำขยายของงานนำเสนอ รายละเอียดความต่างจากเอกสารอยู่ใน `docs/CHANGELOG.md`

รอบนี้หยุดที่ V1 รอเจ้าของงานดู ก่อนสร้างฉากจัดรถ คนขับ บัญชี และผู้ดูแลระบบ
