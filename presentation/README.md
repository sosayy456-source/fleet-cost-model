# เว็บนำเสนอโมเดลต้นทุนการเดินรถ

เปิดเรื่อง (สไลด์ปัญหา/ทางออก) แล้วตามด้วยวิดีโอสาธิตแอปจริงครบ 5 ฝ่าย ยาวประมาณ 2 นาที วิดีโอที่ตัดแล้วอยู่ใน `public/clips/tour.webm` และ `tour.mp4` ใช้ข้อมูลตัวอย่าง

หน้าจำลองทีละขั้นรุ่นก่อน (R0 เลือกหน้าที่ · R1 ฝ่ายบริการลูกค้า) ถูกตัดออกทั้งโค้ดแล้วตามที่เจ้าของงานสั่งเมื่อ 26 ก.ย. 2569 เอกสารใน `docs/` ยังเป็นบันทึกของรุ่นนั้น

## เปิดดู

```powershell
cd presentation
npm.cmd ci
npm.cmd run dev        # เปิด URL ที่ Vite แสดง (ถ้าแอปหลักรันอยู่ที่ 5173 จะได้พอร์ตถัดไป)
```

ส่งต่อแบบไม่ต้องต่อเน็ต: `npm.cmd run build` แล้วเปิด `dist/index.html` โดยให้มีโฟลเดอร์ `dist/clips/` อยู่ข้างกัน สคริปต์ สไตล์ และฟอนต์ฝังไว้ในไฟล์แล้ว แต่วิดีโอเป็นไฟล์แยก เก็บ `dist/OFL.txt` คู่กันด้วย

- `→` ไปช่วงถัดไป · `←` ย้อนกลับ · `Space` หยุด/เล่น
- `1`–`5` ข้ามไปฝ่ายนั้น · `F` เต็มจอ

## ตัดวิดีโอใหม่

ตารางช่วงเวลา ความเร็ว จุดซูม และการ์ดตัวเลข อยู่ใน `src/data/tour.json` ไฟล์เดียว หน้าเว็บกับตัวตัดคลิปอ่านไฟล์นี้ร่วมกัน

```powershell
python tools/build-tour.py "clips/<ไฟล์ที่อัด>.mp4"
```

แก้ `tour.json` แล้วต้องตัดคลิปใหม่ ไม่งั้นคำอธิบายบนจอจะไม่ตรงกับภาพ คลิปดิบใน `clips/` ไม่เข้า Git เพราะใหญ่เกิน 100 MB

## การตรวจ

`npm.cmd run build` ตรวจ TypeScript งบขนาด (JS gzip ≤ 300 KB · ไม่นับวิดีโอ) และไฟล์ออฟไลน์
