# แผนที่ประเทศไทย + 5 เส้นทางทำกำไรสูงสุด

แผนที่ SVG สไตล์ Google Maps แสดงขอบเขต 77 จังหวัด และเส้นทางขนส่งที่คลิกเลือกได้

## โครงสร้าง

```
thailand-map/
├── index.html        โครงหน้า (การ์ดรายการเส้นทาง, legend, scale)
├── package.json      สคริปต์ dev / build / preview (Vite)
└── src/
    ├── data.js       ★ 5 เส้นทางกำไรสูงสุด: พิกัด ตัวเลขกำไร
    ├── network.js    ★ เครือข่ายจุดขึ้นลง: พิกัด 32 จุด + 326 เส้นทาง (จาก จุดขึ้นลง.xlsx)
    ├── roads.js      โครงข่ายทางหลวงหลักแบบย่อ ใช้วาดแนวเส้นทางของเครือข่าย
    ├── map.js        จุดเริ่มโปรแกรม: วาดแผนที่ด้วย d3-geo + ตรรกะการเลือกเส้นทาง
    └── styles.css    สไตล์ทั้งหมด + ตัวแปรสี (:root)
```

## รันในเครื่อง

ต้องมี Node.js 18 ขึ้นไป

```bash
cd thailand-map
npm install        # ครั้งแรกครั้งเดียว
npm run dev        # เปิด http://localhost:5173 ให้อัตโนมัติ
```

คำสั่งอื่น: `npm run build` (ได้ไฟล์ใน `dist/`), `npm run preview` (ลองเปิดไฟล์ที่ build แล้ว)

## แก้ข้อมูล

### เครือข่ายจุดขึ้นลง (`src/network.js`)

- `STOPS` — ชื่อจุด → `c:[lon, lat]`, `group` (`"north"` สาขาภาคเหนือ / `"bkk"` จุดลงกรุงเทพฯ), `approx:true` = พิกัดโดยประมาณ
- `PAIRS` — `[สาขาต้นทาง, จุดลง]` หนึ่งแถวต่อหนึ่งเส้นทาง
- แนวเส้นทางคำนวณจาก `src/roads.js` (หาเส้นทางสั้นที่สุดบนโครงข่ายถนน) ถ้าเพิ่มจุดใหม่ ต้องเพิ่มถนนที่เชื่อมจุดนั้นใน `ROAD_EDGES` ด้วย ไม่งั้นจะวาดเป็นเส้นตรง
- เปิดมุมมองเฉพาะด้วยลิงก์ เช่น `http://localhost:5173/#stop=ตลาดไท&view=bkk` (`view`: `bkk` | `north`)

### 5 เส้นทางกำไรสูงสุด (`src/data.js`)

ทุกอย่างอยู่ใน `src/data.js`

- `ROUTES` — 5 เส้นทาง: `from`, `to`, `profit`, `color` (ตัวเลขกำไรตอนนี้เป็นค่าประมาณจากกราฟ)
- `ORIGIN` — พิกัดจุดต้นทาง `[lon, lat]`
- `CORRIDOR` — แนวถนนหลัก เรียงจากใต้ขึ้นเหนือ; เส้นทางแต่ละเส้นคือช่วงของแนวนี้
- `IDX` — ปลายทางแต่ละแห่งอยู่ที่ index ไหนของ `CORRIDOR` (เพิ่มปลายทางใหม่ได้)
- `CITIES` / `COUNTRIES` / `SEAS` — ป้ายชื่อบนแผนที่

เพิ่มเส้นทางใหม่: เพิ่ม origin ใน `ORIGIN`, เพิ่ม index ปลายทางใน `IDX`, แล้วเพิ่ม object ใน `ROUTES`
(ควรปรับค่าเยื้องเส้น `(i - 2) * 3.2` ใน `src/map.js` ถ้าจำนวนเส้นไม่ใช่ 5)

## ข้อมูลภายนอก

- ขอบเขตจังหวัด: [OpenGISData-Thailand](https://github.com/chingchai/OpenGISData-Thailand)
- ประเทศเพื่อนบ้าน: world-atlas (Natural Earth, public domain)
- d3 / topojson-client ติดตั้งผ่าน npm

ต้องต่ออินเทอร์เน็ตตอนเปิด ถ้าอยากใช้ออฟไลน์ ให้ดาวน์โหลด GeoJSON/TopoJSON มาไว้ใน `public/data/`
แล้วแก้ `DATA_PROVINCES` / `DATA_WORLD` ใน `src/data.js` เป็น `"/data/ชื่อไฟล์"`
