วิธีเปิดโมเดล (ไม่ต้องติดตั้งโปรแกรมเพิ่ม)

ขั้นแรกทุกเครื่อง: คลายไฟล์ zip ให้ครบทั้งโฟลเดอร์ (ห้ามเปิดจากในไฟล์ zip ตรง ๆ)

── Windows ──────────────────────────────────────
1. เปิดโฟลเดอร์นี้ คลิกช่องที่อยู่ด้านบนของหน้าต่าง พิมพ์ cmd แล้วกด Enter
2. พิมพ์   run-model   แล้วกด Enter   (หรือดับเบิลคลิกไฟล์ run-model.cmd)
3. ถ้าขึ้นกล่องเตือน SmartScreen ให้กด "More info" แล้วกด "Run anyway"

── Mac ──────────────────────────────────────────
1. เปิดโปรแกรม Terminal (กด Command+Space พิมพ์ Terminal แล้วกด Enter)
2. พิมพ์   sh   แล้วเว้นวรรคหนึ่งครั้ง จากนั้นลากไฟล์ run-model.sh จาก Finder มาวางในหน้าต่าง Terminal แล้วกด Enter
3. ถ้าขึ้นหน้าต่างให้ติดตั้ง "command line developer tools" ให้กด Install รอจนเสร็จ แล้วทำข้อ 2 ใหม่

── หลังจากนั้น ──────────────────────────────────
เบราว์เซอร์จะเปิด http://localhost:4174/fleet-cost-model/ ให้เอง
ถ้าไม่เปิด ให้คัดลอกที่อยู่ที่ขึ้นในหน้าต่าง cmd/Terminal ไปวางในเบราว์เซอร์ (Chrome / Edge / Safari)
ระหว่างใช้งานห้ามปิดหน้าต่าง cmd/Terminal · เลิกใช้กด Ctrl+C หรือปิดหน้าต่าง

หมายเหตุ
- ต้องต่ออินเทอร์เน็ต เพื่อให้แผนที่โหลดขอบเขตจังหวัดได้ (ส่วนอื่นใช้ได้แม้ไม่มีเน็ต)
- ถ้าพอร์ต 4174 ถูกใช้อยู่ ระบบจะเลือก 4175, 4176, ... ให้เอง ดูที่อยู่จริงในหน้าต่าง cmd/Terminal
