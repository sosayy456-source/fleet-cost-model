รายการทั้งหมด

รายการที่บันทึกไว้ · บันทึกลง Google Sheet ของคุณ (จุดเขียว = ซิงก์แล้ว)

⚙ ตั้งค่าการเชื่อม Google Sheet ยังไม่เชื่อม
วิธีตั้งค่า (ทำครั้งเดียว):
1. เปิด Google Sheet → เมนู ส่วนขยาย (Extensions) → Apps Script
2. ลบโค้ดเดิม วางโค้ดจากไฟล์ AppsScript-โค้ด.gs แล้วกดบันทึก
3. กด Deploy → New deployment → เลือก Web app · Execute as: Me · Who has access: Anyone → Deploy แล้วอนุญาตสิทธิ์
4. คัดลอก Web app URL (ลงท้าย /exec) มาวางช่องด้านบน → บันทึกลิงก์ → ทดสอบ

เคย Deploy ไว้แล้วแต่ข้อมูลไม่ขึ้นชีต? = โค้ดในชีตเป็นเวอร์ชันเก่า
วางโค้ดใหม่ทับ → บันทึก → Deploy → Manage deployments → กดดินสอ ✏ ที่ deployment เดิม → ช่อง Version เลือก New version → Deploy · URL เดิมใช้ต่อได้ไม่ต้องเปลี่ยน
(กด “ทดสอบการเชื่อมต่อ” แล้วต้องขึ้น โค้ด v3 จึงจะบันทึกได้)

ระบบจะสร้าง 2 ชีต: บันทึกเดินรถ (1 แถว = 1 ใบรายการ) และ รายการลูกหนี้ (1 แถว = ลูกหนี้ 1 ราย)
เลขที่ใบรายการวันที่เส้นทางประเภทรถชนิดรถ รายได้ต้นทุนรวมสูญเปล่ากำไร/ขาดทุนสถานะแก้ไข
ยังไม่มีรายการ — ไปที่ “บันทึกข้อมูล” เพื่อเพิ่มรายการ

รายการลูกหนี้

แยกเป็นรายบิล (ลูกหนี้แต่ละราย) · กดปุ่ม “ชำระ” เมื่อลูกหนี้มาจ่าย · ต้องจ่ายครบทุกรายในใบรายการเดียวกัน สถานะในหน้า “รายการทั้งหมด” จึงเปลี่ยนเป็น ชำระแล้ว

🔴 ค้างชำระ (0)
เลขที่ใบรายการเลขที่บิลผู้ส่งผู้รับวันที่เส้นทาง ยอดบิลรายได้ประเภทการชำระค้างชำระ (วัน)ชำระ
ไม่มีรายการค้างชำระ 🎉
🟢 ประวัติการชำระ (0)
เลขที่ใบรายการเลขที่บิลผู้ส่งผู้รับวันที่บิลวันที่ชำระเส้นทาง ยอดบิลรายได้ประเภทการชำระใช้เวลา (วัน)
ยังไม่มีประวัติการชำระ
